# Tiny World

A tiny procedural planet with its own weather. Spin it, change the sky, and sculpt the land.

**Play:** https://senzaiken.github.io/tiny-world/

On iPhone, open it in Safari and use Share → Add to Home Screen to run it full-screen.

Built with [Three.js](https://threejs.org) as a single static page. Design notes live in [`docs/`](docs/README.md).
